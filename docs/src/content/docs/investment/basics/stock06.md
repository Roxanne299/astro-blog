# **如何投资烟蒂股？一些需要注意的事项**

## **一、烟蒂股投资的核心原则**

### **基本选股标准**

- **负债率相对低** + **资产质量高** + **PB低** + **现金类资产占比高**
- **不预测涨跌时机**（很难把控，段位不高时按规则走比预测更安全）
- **买在分歧**：烟蒂股一定是有分歧的，严格按照标准持股

### **为什么分歧永远存在？**

分歧始终存在（管我财投资了格力，但格多没有，因为两个人看法不一样），这很正常。**买在分歧，卖在一致**是烟蒂股投资的核心逻辑。

------

## **二、不同的烟蒂投资风格**（雪球平台）

### **1. 分散投资风格**（推荐新手）

- **代表人物**：管我财（港股为主）、貔貅PX（A股为主）
- **持股数量**：20-30支，甚至更多
- **优势**：分散度高，为了安全睡得着，更大的安全边际
- **适合人群**：不深入研究公司的投资者

### **2. 集中投资风格**（高难度）

- **代表人物**：格多巴卡
- **持股数量**：15支股票，头部集中
- **难度**：集中 >> 分散
- **要求**：需要深入研究，有把握才能集中

### **市场特点**

- **港股**：烟蒂股多
- **A股**：烟蒂股少

------

## **三、烟蒂股能否加杠杆？**

### **谨慎加杠杆的条件**

集中投资烟蒂股要看那些**趋势容易判断的**：

- **水泥**：跟着国家政策走，供给侧决定股价，国家会保护水泥行业，有确定性
- **赌博类**：走势可测算的行业
- 可测算和可预估的行业

### **为什么不建议集中+低估？**

- 集中投资需要深入研究能力
- 对可测算性要求极高
- **太难了**，建议普通投资者选择分散+低估

## **四、核心财务指标解读**

### **1. PB (Price-to-Book) — 市净率**

**本质**：你花1块钱能买到多少"账面资产"

**买菜比喻**：

- 白菜账面价：5元/斤
- 市场打折价：3元/斤
- **PB = 3 ÷ 5 = 0.6**
- 你花1块钱能买1.67斤白菜（便宜40%）

**烟蒂股标准**：**PB<1**（价格低于资产价值）+ **资产质量高**

### **2. PE (Price-to-Earnings) — 市盈率**

**本质**：你花1块钱能买到多少"公司赚钱能力"

**奶茶店比喻**：

- 花100万买奶茶店，去年赚10万
- **PE = 100万 ÷ 10万 = 10** → 付了10年利润买下它

**重要警告**：烟蒂股通常PE很高（甚至亏损），**不能用PE判断烟蒂股**

### **3. TTM (Trailing Twelve Months) — 过去12个月**

**本质**：用"最近12个月的真实数据"代替"去年数据"

**优势**：比传统年报更及时

- 传统年报：2023年1-12月（已过时3个月）
- TTM数据：2023年4月-2024年3月（最新12个月）

## **五、烟蒂股投资的"安全边界"**

| **操作**     | **正确做法**                    | **错误做法**           |
| ------------ | ------------------------------- | ---------------------- |
| **资金管理** | 用**不超过10%的本金**买入烟蒂股 | 用全部本金+杠杆押注    |
| **持有时间** | 持有**1-3年**，等待价值回归     | 急躁追涨杀跌，每天盯盘 |
| **止损纪律** | 股价跌破**PB=0.3**立即止损      | 不设止损，死扛         |
| **资产验证** | 重点看**现金/总资产>20%**       | 只看PB<1，忽略资产质量 |

## **六、价值评估为什么需要时间？**

### **核心原理**

**价值不是"账上写多少"，而是"能卖多少钱"**

### **价值重估需要时间的原因**

1. **公司需出售资产**（如卖地、剥离业务）
2. **行业周期反转**（如钢铁需求恢复）
3. **市场情绪转变**（从"垃圾股"到"被低估"）

**→ 这个过程最少1年，通常2-3年**

### **价值评估三步骤**

| **步骤**              | **做什么**                     | **为什么需要时间**           |
| --------------------- | ------------------------------ | ---------------------------- |
| **验证净资产真实性**  | 看财报"应收账款""固定资产减值" | 需时间查证（看3年财报）      |
| **验证现金/资产比例** | 现金占总资产>20%（安全）       | 需确认现金真实存在           |
| **验证资产可变现性**  | 土地有开发证？设备能卖？       | 需联系公司/政府，至少1-2个月 |

------

## **七、烟蒂股投资决策表格**

建议制作以下决策表格来系统分析：

- 股票名
- 利好因素/不利因素
- 安全边际
- 胜率（价值回归明确证据）
- 4年赔率
- 负债率 + 有息负债率
- 流动资产与总资产（扣负债）
- 流动资产与市值（扣负债）
- 7年自由现金流
- 最近ROE + 股息率
- 当前PB + 当前PB所处1/5/10年分位
- 当前PE TTM + PB*PE TTM
- 机构评级（6个月内）
- 大股东背景

**根据表格内容结合利好因素和安全边际算出胜率和4年赔率**

------

## **八、核心结论**

✅ **烟蒂股投资本质是"用时间验证安全垫"，而不是"用数字算便宜"**

✅ **严格按标准执行，不预测时机，买在分歧，耐心等待价值回归**

✅ **新手建议：分散投资 + 低估值 + 不加杠杆**
